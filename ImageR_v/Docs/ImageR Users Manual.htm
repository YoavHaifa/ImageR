1.      Basic imaging with a single images’ series

1.1  How to open a file or files for viewing?

There are several ways to open a file or a series of files for viewing by ImageR.

·         Open ImageR and from the menu use <File>Open>, then select the file that you want to view. Notice that if in the same directory there is a series of files which differ only in one index field, ImageR will, be default, open all the images in the series and allow you to leaf between them.

·         In Windows, you have the application file icon (with red “IR” letters on blue background) where the application executable is saved. You can drag your file’s icon and drop it on ImageR’s icon.

·         You can create a shortcut for ImageR on your desktop and drop your files on it for viewing.

·         You can use Window’s <Open With> option for you file, or even let Windows remember ImageR as the default app to open some type of files.

1.2  How to set the dynamic range (“windowing”)

Usually, ImageR displays all images in 256 gray levels (the standard for black-and-while images).

 The values of pixels in the image matrix can be of different dynamic range. It could be very small (for example, in the range [0 - 1] for some floating-point data) or very large – maybe in the millions.

Typical CT images are of the numeric range [0 - 4095] or, if Hounsfield Units are used, may be [-1024 – 3071], or some other vendor dependent variant.

The translation of the original pixel values to gray levels is done through a simple “window” function, which is defined by 2 parameters: center and width. The current value of the window parameters are displayed in the two rightmost fields at the status bar at the bottom of the ImageR app window.

There are several ways that the user can adjust the windowing function:

·         Interactively, by the mouse, dragging the mouse while the central button is pressed:

o   Vertical movement change the window’s center

o   Horizontal movement change the window’s width

·         Using keyboard shortcuts:

o   <ctrl-f> - Image R will try to adjust the window for best viewing of the area at the center of the display rectangle

o   Adjust the window to a special area, by two steps:

§  Use the mouse to left-click on the point of interest

§  <ctrl-l> to instruct ImageR to adjust the window for the selected point

·         Using special Windowing GUI

o   Invoke the windowing GUI by <ctrl-w>

o   Use the two handles to control the center and the width – dragging them vertically up or down

o   Or, insert numerical values in the edit-windows below

o   Notice the changes in the window’s visualization on the right side of the window’s GUI and the real-time changes in the image display

1.3  Controlling image zoom and shift

ImageR may apply zoom and shift to the image before it is displayed. The user can control them in several ways:

·         Interactive Zoom: Hold down the <ctrl> key AND the mouse left button and drag the mouse up for zoom-in or down for zoom-out.

·         Interactive Shift: Hold down the <shift> key AND the mouse left button and drag the mouse to shift the image in the wanted direction.

·         Use <ctrl-z> to invoke special Zoom GUI, where you can:

o   Insert zoom factor as a number

o   Select zoom mode

§  Bi-Cubic is designed to give better image quality

§  Bi-Linear (the default)

§  Duplicate – shows only original values without interpolation. Each value may be duplicated according to the zoom factor.

§  Disable – prevents interactive change of the zoom factor

1.4  Leafing between images

Note that ImageR, by default, is designed to work with series of images. Basically, there are two types of series:

·         A series of files in the same directory with numeric field in the files’ names that is used as counter.

·         A single file that is a 3D matrix of binary values

When a single file is loaded, ImageR checks whether there is a related series of images that can be displayed.

The second field (from the right) in the status bar at the bottom of ImageR app window shows the index of the current image in the series and the number of images in the whole series. It may show something like “Page 1/280”.

You may note that the first field in the status bar sometimes disappear, so the “page” field becomes the first. You may extend ImageR’s window horizontally to give more space to the status bar.

There are several options for the user to decide which image would be display:

·         If there is a series of files, the file that was first selected will appear first in the display.

·         Interactively leafing through the images’ series: Press the mouse left button and move the mouse up and down.

o   Upward movement goes toward the first image

o   Downward movement goes toward the last image

o   Note that when the first (or the last) image is displayed – there is a special not in the first field of the status bar.

·         Go To a selected image: Press <ctrl-g> and enter the index of the wanted image.

·         Go to the first image: <ctrl>+<Home>

·         Go to the last image: <ctrl>+<End>
